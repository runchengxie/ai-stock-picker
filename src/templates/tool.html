01 / FROM INPUT TO OUTPUT

A small tool with a clear job.

It starts after you build a candidate pool. It does not fetch prices, backtest a strategy, or place orders.

01

Bring your candidates

Use a supported JSON or CSV file. Choose a signal date, selection count, and ranking style.

02

Get another perspective

DeepSeek handles A-shares. Gemini handles US stocks. The model can only choose from your pool.

03

Check before saving

Validate the structure, count, unique symbols, and explanations. Invalid responses are rejected.

04

Keep the record

Save the result alongside inputs, the exact prompt, sanitized requests, raw responses, and hashes.

02 / YOUR FIRST RUN

Start with a sample. No key required.

Install Python 3.10–3.12 and uv, then paste these commands into your terminal.

Install uv ↗

The historical A-share sample has one candidate. A dry run checks the input and shows a plan summary. It does not read credentials, call a model, or save a result.

Ready to call a model? Read the usage guide ↗
● ● ●~/ai-stock-picker

1. Install

git clone https://github.com/runchengxie/ai-stock-picker.git
cd ai-stock-picker
uv sync --locked --no-dev

2. Check the bundled sample

uv run aipick cn pick \
  --candidates examples/cn_candidates.json \
  --as-of 2026-06-30 \
  --top-n 1 \
  --style momentum \
  --dry-run
