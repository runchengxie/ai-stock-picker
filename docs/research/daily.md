# Daily observations: what do we actually have?

English · [简体中文](../zh-CN/research/daily.md)

## The question

Historical replay helps debug an idea. A daily observation asks a different question: what did the process decide before later outcomes were known?

## What is included now

The reviewed website snapshot does **not** include a verified continuous daily series. This does not establish that no other files exist; it means no such series has been verified and published in this snapshot. The available note records an offline rehearsal run on July 18, 2026 for the July 17 signal date.

The rehearsal used prepared responses, made zero OpenAI/DeepSeek API calls, and measured no later returns. It is not recent model performance.

## What the rehearsal found

The bounded selection repeated the numeric Top10. A majority veto changed one stock, but a simple deterministic control made the same stock change. The exercise therefore did not show that GPT added useful information.

It did find a provenance problem: the frozen plan named DeepSeek while the shadow manifest named OpenAI. The run remains an unbound historical rehearsal. Reproducible selections do not fix that mismatch.

Three repeated logical runs were recorded, but duplicate response bytes and shared timestamps do not establish independent model samples.

## What comes next

Future publication must validate the owner day bundle: three repetitions, the consensus, file hashes, and the frozen decision/launch bindings. Failed terminal states stay in the series; do not remove failed days to make the picture look better.

The page has an importer for these validated day bundles. It publishes only date, model/arm, status, valid repetition count, and evidence fingerprints. It does not publish stock lists, Prompts, raw responses, credentials, or machine paths. Without outcome data and a specified execution method, it does not draw return curves.

## What this still cannot prove

A complete launch binding shows which inputs and model were used. It does not repair missing historical timing proof or turn a research-only record into qualified out-of-sample evidence.
